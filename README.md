# ระบบเช็คชื่อเข้าเรียน (Student Attendance Form) ด้วย JSONP + Google Apps Script

แอปพลิเคชันสำหรับเช็คชื่อนักศึกษา บันทึกข้อมูลลง Google Sheets โดยตรงผ่านเทคนิค **JSONP** ข้ามข้อจำกัด Cross-Origin Resource Sharing (CORS) โดยไม่ต้องใช้ `<iframe>` พร้อมการแจ้งเตือนสวยงามด้วย **SweetAlert2**

---

## 📁 ไฟล์ในโปรเจกต์
1. `index.html` : หน้าเว็บฟอร์มเช็คชื่อ ออกแบบด้วย Tailwind CSS + SweetAlert2 + ฟังก์ชัน JSONP Callback
2. `Code.gs` : โค้ด Google Apps Script ฝั่ง Server สำหรับรับค่าและบันทึกลง Sheet

---

## 🛠️ ขั้นตอนการนำโค้ด `Code.gs` ไปติดตั้งใน Google Sheets

1. เปิด **Google Sheets** ที่ต้องการเก็บข้อมูล
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ลบโค้ดเดิมออกทั้งหมด แล้ววางโค้ดจาก `Code.gs`
4. คลิกปุ่ม **บันทึก (Save)** (รูปแผ่นดิสก์)
5. คลิกปุ่ม **การทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
6. เลือกประเภทเป็น **เว็บแอป (Web app)**
   - คำอธิบาย: `ระบบเช็คชื่อ v1`
   - เรียกใช้ในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้ส่งข้อมูลได้โดยไม่ต้องล็อกอิน)*
7. คลิก **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web App URL)**
8. นำ URL ที่ได้ไปวางแทนที่ตัวแปร `SCRIPT_URL` ในไฟล์ `index.html` (หากใช้ URL อื่น)
